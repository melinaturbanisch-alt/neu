# Google-Ads-Kampagne „Website-Bau“ — Vorlage zum Einfügen

## Einstellungen
| | |
|---|---|
| Kampagnentyp | **Suche** (ohne Ziel-Assistent oder Ziel „Leads“) |
| Netzwerke | **Suchnetzwerk-Partner AUS, Displaynetzwerk AUS** |
| Standorte | **Hungen + Umkreis 100 km** (Standort → „Umkreis“ → Hungen, 100 km). Deckt u. a. Frankfurt, Gießen, Marburg, Fulda, Wiesbaden, Darmstadt ab |
| Standortoption | **„Präsenz: Personen, die sich in Ihren Zielregionen befinden“** |
| Sprache | Deutsch |
| Budget | ab ca. 15–20 €/Tag. Im Rhein-Main-Gebiet ist die Konkurrenz groß, deshalb CPC-Limit setzen und Suchbegriffe eng beobachten |
| Gebote | Start: **„Klicks maximieren“ mit max. CPC-Limit ~3–4 €** → nach 15–30 Conversions auf „Conversions maximieren“ |
| Werbezeiten | Mo–Sa, z. B. 7–20 Uhr (passt zu „erreichbar Mo–Sa“) |
| Automatisch angewendete Empfehlungen | **AUS** (Tools → Empfehlungen → automatisch anwenden) |
| Ziel-URL | `https://www.melvona.de/website` |
| Conversions / Zielvorhaben | In der Kampagne **beide** Zielvorhaben auswählen: **„Lead-Formular senden“** (→ Anfrage über Formular) **und „Kontakt“** (→ Klick auf Telefonnummer). „Kontakt“ ist kein Konto-Standardziel und zählt sonst nicht! |

## Anzeigengruppe 1: Website erstellen lassen
Keywords (Wortgruppe = in "Anführungszeichen", genau = in [Klammern]).
Start mit Wortgruppe; CPC-Limit setzen, weil die Begriffe umkämpft sind.

```
"homepage erstellen lassen"
"webseite erstellen lassen"
"website erstellen lassen kosten"
"homepage erstellen lassen kosten"
"firmenwebsite erstellen lassen"
"website für selbstständige"
"website für kleine unternehmen"
"webdesign agentur"
"webdesigner"
```

## Anzeigengruppe 3: Website bauen in der Nähe
Für Leute, die gezielt jemanden aus der Umgebung suchen. Google nutzt bei „in der Nähe“
den Standort der suchenden Person, das passt genau zum 100-km-Umkreis.
```
"webdesigner in der nähe"
"webdesign in der nähe"
"webagentur in der nähe"
"website erstellen lassen in der nähe"
"homepage erstellen lassen in der nähe"
"website bauen lassen in der nähe"
"webdesigner nähe"
"webdesign agentur in der nähe"
```

1. Webdesigner in Ihrer Nähe  ← an Position 1 fixieren
2. Website erstellen lassen
3. Agentur aus Mittelhessen
4. Auch Termine vor Ort
5. Websites ab 854 €
6. In 1–2 Wochen online
7. Kostenloses Erstgespräch
8. Festpreis-Angebot vorab
9. Persönlich statt Callcenter
10. Kein Baukasten – individuell
11. Feste Ansprechpartner
12. Jetzt Erstgespräch sichern

Beschreibungen (max. 90 Zeichen, alle geprüft):
1. Ihre Webagentur aus der Region: persönlich, vor Ort oder per Video-Call. Ab 854 €.
2. Basis-Website ab 854 €: Startseite, Leistungen, Kontakt, Impressum & Datenschutz.
3. Kostenloses Erstgespräch in 15 Minuten. Danach festes Angebot, keine offene Rechnung.
4. Schnell, mobil, individuell gestaltet. In 1–2 Wochen ist Ihre neue Website online.

Tipp: Wenn ihr ein **Google-Unternehmensprofil** habt, unter Assets als **Standort** verknüpfen.
Bei „in der Nähe“-Suchen zeigt Google dann Adresse und Entfernung direkt in der Anzeige.
